# Configuration

Every threshold the pipeline uses lives here, not in code. Files marked **frozen** are pre-registered and never
edited; later choices are read on top of them and recorded in an ADR.

| File | What it holds | Read by |
|---|---|---|
| `languages.yml` | The ranking of Wikipedias by human article views and `top_n` (30) | ingestion, scoring, app export (ADR 0006) |
| `namespaces.json` | Localised namespace names and main pages of the candidate wikis | the article filter (`lookedup/parse.py`) |
| `analytics.yml` | **Frozen.** Phase 2 spike, baseline, automation and event rules, ablations, evaluation settings | warehouse, scorer, evaluations |
| `analytics_v2.yml` | Phase 2b additions read on top of `analytics.yml`: the single-language share | events (ADR 0019) |
| `product.yml` | Product settings: events need 2 languages, and the breadth tiers | app events (ADR 0021) |
| `language_geo.yml` | Countries where each language is official or the majority language | the globe (ADR 0023), generated by `python -m lookedup.language_geo` |
| `forecast_params.json` | Hyperparameters chosen on validation for each forecast model | training and retraining (ADR 0029) |
| `live.yml` | Live-layer burst rules as tuned in ADR 0032 | the Python reference (`live/`) and the Worker (`worker/src/rules.json`) |
| `live_prereg_phase5.yml` | **Frozen.** The live rules as pre-registered for Phase 5 | H9 and H10 (`lookedup/live_analysis.py`) |
